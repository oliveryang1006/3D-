# 功能需求清单

## 管理后台（Web 系统）

### 1. 会员管理
- **会员列表**：按手机号、姓名、等级、注册时间搜索并查看全部会员。
- **会员详情**：展示姓名、手机号、持有卡券、核销记录、消费记录、转赠记录。
- **会员操作**：支持发放/冻结会员卡。

### 2. 卡券核销
- **统一核销台**：提供扫码和手动输入券码功能，授权管理员可核销任意会员的券码。

### 3. 产品管理
- **会员卡设置**：创建/发放电子会员卡（1988 元、2888 元、2688 元）；配置卡名称、图标、购买价格、有效期及附带权益（如折扣率）。
- **券包设置**：创建单张券（满减券、无门槛代金券、房型升级券等）；配置券名称、类型、面值、使用门槛、有效期、总发放量及每人限领张数。

### 4. 基础数据
- **场景维护**：维护核销场景（中餐厅、西餐厅、前台、康体中心等），核销时必须选择场景，便于统计。
- **核销用户管理**：为各场景创建核销员账号，并与角色权限关联。
- **销售人员管理**：录入销售团队信息，用于会员注册或购卡绑定，计算销售业绩。

### 5. 报表查询
- **核销记录报表**：所有核销流水，支持按日期、场景、核销员、券类型筛选导出。
- **剩余产品报表**：统计当前未发放/未使用的会员卡、券包、优惠券库存。
- **过期产品报表**：统计已过期卡券明细。
- **转赠报表**：记录所有卡券转赠的赠送方、接收方、时间和卡券信息。
- **有效期修改报表**：记录人工修改卡券有效期的操作日志（操作人、时间、修改前后值）。
- **注销记录报表**：记录手动注销的卡券信息及操作人。

### 6. 系统管理
- **用户管理**：创建和管理后台员工账号。
- **角色管理**：定义角色（超级管理员、财务、运营经理、核销员等）并配置权限。
- **菜单管理**：控制后台导航菜单及角色可见性。
- **操作日志**：记录关键操作（登录、重要设置变更等）。

## 商户核销端（响应式 Web 页面）

- **登录页**：核销员通过手机号与密码登录。
- **核销工作台**：
  - 扫码核销：调用摄像头扫描会员二维码。
  - 手动核销：输入券码完成核销。
  - 场景选择：核销前必须选择所在场景（如中餐厅）。
  - 核销记录：仅可查看自身核销记录。

## 会员端（微信公众号内 H5 页面）

- **微信一键登录**：关注公众号后授权手机号自动注册/绑定会员。
- **我的会员卡**：展示全部电子会员卡，包括卡面、等级、卡号、有效期。
- **我的卡券**：以「未使用」「已使用」「已过期」标签页展示卡券；查看详情时显示使用说明、独立核销二维码与券码。
- **转赠功能**：可转赠卡券支持分享给微信好友，生成赠卡海报或链接。
- **个人中心**：查看/编辑姓名等基本信息，并查看积分明细和消费记录。
